# خطة إكمال لوحة التحكم

بناءً على ما تم إنجازه في المراحل 1–3 (المصادقة، RLS، سجلات التدقيق، إدارة المشاريع/الخدمات/المقالات، مكتبة الوسائط، ربط الواجهة العامة بقاعدة البيانات)، إليك الخطوات المتبقية:

---

## المرحلة 4 — إكمال أدوات إدارة المحتوى

### 1. إدارة الصفحات (`/admin/pages`)
- محرر لكل صفحة ثابتة: الرئيسية، من أنا، الباقات، التواصل.
- حقول لكل صفحة: عنوان SEO، وصف Meta، OG image، Hero heading/subheading، CTA.
- ربط `HomeView` و`PackagesView` و`ContactView` لقراءة النصوص من جدول `pages` بدل i18n hardcoded (مع Fallback).

### 2. إدارة الرسائل (`/admin/messages`)
- جدول عرض `contact_messages` مع فلاتر (غير مقروء/مقروء/مؤرشف).
- تفاصيل الرسالة مع أزرار: تعليم كمقروء، أرشفة، حذف، رد بالبريد.
- عدّاد الرسائل غير المقروءة في الشريط الجانبي (Badge).

### 3. إعدادات الموقع (`/admin/settings`)
- تحرير `site_settings`: البريد الرسمي، رقم الهاتف/واتساب، روابط السوشيال ميديا، شعار الموقع، ألوان العلامة.
- تحرير OG image الافتراضي و Favicon.
- ربط الفوتر والهيدر والـ WhatsApp Widget لقراءة القيم ديناميكيًا.

### 4. الملف الشخصي (`/admin/profile`)
- تحرير الاسم، الصورة الرمزية، تغيير كلمة المرور، تفعيل 2FA (اختياري).

### 5. إدارة الوسوم والتصنيفات (`/admin/tags`)
- CRUD كامل لجدول `tags` و`insight_categories`.
- إحصائيات: عدد المقالات/المشاريع لكل وسم.

### 6. مدير SEO (`/admin/seo`)
- عرض شامل لجميع الصفحات مع حالة SEO (Title/Description/OG/Schema).
- تنبيهات لصفحات تفتقد Meta أو صور OG.
- محاكاة معاينة Google/Twitter/Facebook.
- إدارة `sitemap.xml` و`robots.txt`.

---

## المرحلة 5 — تحسينات جودة الاستخدام

### 7. لوحة تحكم رئيسية غنية (`/admin`)
- إضافة قائمة **النشاط الحديث** (آخر مقالات، آخر رسائل، آخر مشاريع محررة).
- **الأنشطة المجدولة**: مقالات مجدولة النشر.
- مؤشرات أداء: زوار الأسبوع، الرسائل الجديدة، نمو المحتوى.

### 8. سير عمل النشر (Drafts/Scheduling)
- تحسين واجهة الحالة (draft/published/scheduled) في جميع المحررات.
- Cron أو Server Function لنشر المقالات المجدولة تلقائيًا.
- معاينة قبل النشر (Preview mode).

### 9. البحث الشامل داخل اللوحة
- Command Palette (⌘K) للتنقل السريع بين المشاريع/المقالات/الصفحات.

### 10. تجربة المستخدم الشاملة
- شاشات فارغة (Empty States) لكل قائمة.
- Toasts موحدة لكل عمليات الحفظ/الحذف.
- Skeleton loaders أثناء التحميل.
- تأكيد الحذف مع Undo لمدة 5 ثوان.
- Keyboard shortcuts في المحررات (⌘S للحفظ).

---

## الأولوية المقترحة

نبدأ بالتسلسل الأكثر تأثيرًا:

1. **إعدادات الموقع** (لتحكم فوري في بيانات التواصل والفوتر)
2. **إدارة الرسائل** (لأنها بيانات حية وتحتاج متابعة)
3. **إدارة الصفحات** (لتحرير النصوص الرئيسية بدون كود)
4. **مدير SEO** (لضمان جودة الظهور)
5. **الوسوم/التصنيفات + الملف الشخصي**
6. **تحسينات UX + Command Palette + النشر المجدول**

---

## تفاصيل تقنية

- كل محرر جديد يتبع نفس نمط `AdminServiceEditorView` (form + zod + server functions + toast).
- Server functions محمية بـ `requireSupabaseAuth` + فحص `has_role('admin')`.
- كل تغيير حساس يُسجَّل في `audit_logs` تلقائيًا.
- الواجهة العامة تقرأ من `site_settings` و`pages` مع Fallback لـ i18n dictionary.
- لا تعديلات على جداول قاعدة البيانات الحالية — البنية جاهزة، فقط UI + server functions.

---

**من أين نبدأ؟** أقترح البدء بـ **إعدادات الموقع + إدارة الرسائل** في الجولة القادمة لأنهما يعطيانك تحكمًا فوريًا مرئيًا على الموقع.
